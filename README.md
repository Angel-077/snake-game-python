# Snake Game

This repository contains a Python Snake game built with Tkinter and a browser version.

## Run the Python game

Python 3 with Tkinter is required. From the repository directory, run:

```powershell
python snake_game.py
```

Use the arrow keys or WASD to steer. The best score is saved in `snake_best_score.txt`.

## Run the browser version

Open `index.html` in a browser, or serve this directory locally:

```powershell
python -m http.server 8000
```

Then open http://localhost:8000.
